# pickipv4

Pick lightweight ipv4 statistics from stdin samples.

**Site:** https://theworker02.github.io/pickipv4/

## Install / run

```bash
git clone https://github.com/theworker02/pickipv4.git
cd pickipv4
node src/cli.js
node --test
```
